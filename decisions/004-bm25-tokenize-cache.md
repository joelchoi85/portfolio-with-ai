# 004. BM25 형태소 분석 캐시 — 기동 185초 → 1.9초

RFP RAG System · 2026-09-06 ~ 07 · 커밋 `6c1f2bc`, `a468ca8`, `af755ef`

## 맥락

새 청크를 반영하려면 API를 재시작해야 했고 재시작에 3분이 걸렸다. 그래서 갱신은 밤에만 돌렸다.

## 측정

기동 시간을 쪼개 봤다.

| 단계 | 시간 |
|---|---|
| 형태소 분석 (Kiwi) | 184.4초 |
| BM25 색인 구축 | 0.8초 |

색인은 매번 새로 만들어도 된다. 비싼 건 분석이었다.

## 결정

형태소 분석 결과를 **본문 해시**로 캐시한다. 청크 이름으로 찾으면 코퍼스 버전이 바뀔 때마다 캐시가 깨지는데, 본문 해시는 내용이 같으면 그대로 맞는다. 캐시가 다 맞으면 Kiwi를 아예 올리지 않는다.

## 결과

- 기동 185초 → **1.9초**
- RAM 950MB → 487MB
- 재시작 대신 `POST /reload`로 새 청크를 무중단 반영
- 갱신 주기를 밤 1회에서 3시간마다로 늘림

## 배운 것

빠르게 하려면 먼저 어디가 느린지 잰다. 처음 의심한 건 색인 구축이었는데 0.8초짜리였다.
